ClearDisk 2.2.0

Storage and performance checks in one app. Open Performance in the sidebar.

  • See CPU activity, memory pressure, thermal state and running processes, with explanations of common background processes.
  • Review background items, connection information and per-app network activity. An optional speed test uses Apple's networkQuality service after confirmation.
  • Follow CPU and memory charts, keep optional local usage history, and enable an optional menu-bar monitor.
  • Review supported Chrome, Brave and Edge tabs after granting browser Automation access. Review windows, duplicate tabs and estimated extension usage.
  • Use your existing ClearDisk license for performance actions. Quitting apps, changing browser tabs, rebuilding Spotlight's index and restarting require confirmation; protected system processes cannot be quit through ClearDisk.

Monitoring is not a hardware diagnostic or a guarantee of better performance. Available readings depend on macOS permissions and hardware. History stays on your Mac. Login startup is optional. Existing disk cleanup, iCloud Doctor and Mac checks remain available.

Requires macOS 15 or later on Apple silicon or Intel. Existing licenses remain valid.
