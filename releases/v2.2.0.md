# ClearDisk 2.2.0

The WhySlow performance tools are now inside ClearDisk. Open **Performance** in the sidebar for CPU and memory readings, process explanations, background items, internet checks and local usage charts.

- Optional menu-bar monitoring and startup at login.
- Supported Chrome, Brave and Edge tab review with Automation permission; private windows excluded.
- An optional Apple networkQuality speed test after confirmation.
- Confirmed performance actions use your existing ClearDisk license. Core system processes are protected from quit actions.

Disk cleanup, iCloud Doctor, Apple Intelligence storage and Intel-app checks remain available. Monitoring is not a hardware diagnosis or a guarantee of better performance.

Requires macOS 15 or later, Apple silicon or Intel. Signed, notarized and stapled. Existing ClearDisk licenses remain valid. In ClearDisk 2.0.0 or later, choose **ClearDisk → Check for Updates…**, or download the DMG below.
