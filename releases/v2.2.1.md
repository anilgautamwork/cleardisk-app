# ClearDisk 2.2.1

This update brings disk and performance readings within reach and fixes navigation before your first scan.

- **Disk scan**, **Why Slow** and **Permissions** stay visible above the scrolling workspace list.
- Why Slow opens the running-process list with CPU and memory sorting and confirmed quit actions. Protected system processes remain protected.
- A horizontal status bar shows available disk space, CPU load and memory pressure across the app.
- Enable the menu-bar icon from the top bar to see CPU, memory, disk space and up to five running apps, sorted by memory or CPU. Quit buttons open a confirmation in ClearDisk.
- Monitoring runs while the window is open, or while the optional menu bar is enabled; local history follows your existing setting.
- After a completed scan, the menu shows large files, cache measurements and developer junk, with Review links into the app. No files are removed directly from the menu.
- Open Permissions to check disk access, see setup steps or choose a folder instead.
- Back returns to your previous workspace. Opening Permissions preserves scan progress and results.
- Storage sections explain why they are unavailable before a scan finishes.

Existing licenses remain valid. This update does not change macOS permissions for you.

Requires macOS 15 or later, Apple silicon or Intel. Choose **ClearDisk → Check for Updates…** or download the DMG.
