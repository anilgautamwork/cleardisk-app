# ClearDisk 1.0 — Plan 04: Two-Pass Scan and Live Findings

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On a home scan the System Data screen appears as soon as `~/Library` and the dot-folders are measured, the rest of the home folder scans in the background and grafts on, the scanning screen shows live per-bucket totals, a rescan cancels a running pass, and the `tmutil` call never blocks the main thread.

**Architecture:** `Core` gains `ScanBucket` (prefix classification inherited down the tree), `ScanProgress` (files, bytes, per-bucket bytes), a cancel flag in `ParallelScan.Engine`, and `ScanMerge.graft` that attaches pass-two directories onto the live root. `AppState` orchestrates the two passes with a generation counter so stale results are dropped. `SystemDataScan.build` takes the snapshot count as a parameter.

**Tech Stack:** Swift 6, `getattrlistbulk` engine (unchanged), XCTest.

**Spec:** `docs/superpowers/specs/2026-09-05-cleardisk-1.0-production-design.md` (section 8)

## Global Constraints

- Pass one = `~/Library` plus every top-level dot-directory; pass two = every other top-level directory. Top-level files are counted in pass one only.
- Progress callback signature becomes `(ScanProgress) -> Void`; `scan-cli` is updated in the same task.
- Bucket rules (relative to home): `Library/Caches` → caches; `Library/Logs` → logs; `Library/Developer`, `.npm`, `.cargo`, `.gradle`, `.m2`, `.cache`, any directory named `node_modules` → developer; `Downloads` → downloads; `.Trash` → trash; `Library/Application Support/MobileSync/Backup` → backups; `Library/Containers`, `Library/Group Containers` → containers; else other. A child inherits a non-`other` parent bucket.
- Known, accepted limit (ponytail comment in code): a hardlink shared across the two passes counts twice.
- `swift test` green after every task; commit after every task.

```swift
import Foundation

/// Coarse, cheap classification of directories for the live "found X GB of
/// caches so far" counters. Matched once per directory; children inherit.
public enum ScanBucket: String, CaseIterable, Sendable {
    case caches, logs, developer, downloads, trash, backups, containers, other

    public var label: String {
        switch self {
        case .caches: "Caches"
        case .logs: "Logs"
        case .developer: "Developer junk"
        case .downloads: "Downloads"
        case .trash: "Trash"
        case .backups: "iPhone backups"
        case .containers: "App containers"
        case .other: "Everything else"
        }
    }

    private static let byRelativePath: [String: ScanBucket] = [
        "Library/Caches": .caches,
        "Library/Logs": .logs,
        "Library/Developer": .developer,
        ".npm": .developer, ".cargo": .developer, ".gradle": .developer, ".m2": .developer, ".cache": .developer,
        "Downloads": .downloads,
        ".Trash": .trash,
        "Library/Application Support/MobileSync/Backup": .backups,
        "Library/Containers": .containers,
        "Library/Group Containers": .containers,
    ]

    public static func classify(directoryPath: String, name: String, parent: ScanBucket?, home: String) -> ScanBucket {
        if let parent, parent != .other { return parent }
        if name == "node_modules" { return .developer }
        guard directoryPath.hasPrefix(home + "/") else { return .other }
        let relative = String(directoryPath.dropFirst(home.count + 1))
        return byRelativePath[relative] ?? .other
    }
}

public struct ScanProgress: Sendable {
    public var files = 0
    public var bytes: Int64 = 0
    public var bucketBytes: [ScanBucket: Int64] = [:]
    public init() {}
}
```

Replace the whole file with:
```swift
import Darwin
import Foundation

/// Parallel front-end over the bulk engine: a shared work queue of directories
/// serviced by one worker per core (x2, they block in syscalls). Every
/// discovered subdirectory becomes a work item, so granularity is fine enough
/// that one giant subtree cannot serialize the scan.
///
/// Hardlinks are deduplicated exactly across workers by merging each worker's
/// fileID->size map at the end. Subtree node sizes keep each worker's local
/// view of a hardlink; only the totals and root are globally corrected —
/// matching how DaisyDisk-class tools display hardlinks.
// ponytail: one directory is one work item, so a single directory holding
// hundreds of thousands of files (Chrome's Cache_Data) enumerates serially —
// getattrlistbulk iteration state is per-fd, so intra-directory parallelism
// isn't possible with this API. Measured ~2x du, ~4x FileManager; good enough.
public enum ParallelScan {

    public struct Result: Sendable {
        public let root: FileNode
        public let stats: ScanStats
        /// Bytes per bucket (see ScanBucket) — the live counters' final values.
        public let bucketBytes: [ScanBucket: Int64]
        /// True when `isCancelled` fired; the tree is partial and must be discarded.
        public let cancelled: Bool

        public init(root: FileNode, stats: ScanStats, bucketBytes: [ScanBucket: Int64], cancelled: Bool) {
            self.root = root
            self.stats = stats
            self.bucketBytes = bucketBytes
            self.cancelled = cancelled
        }
    }

    public static func scan(path: String,
                            skipPrefixes: [String]? = nil,
                            homePath: String = NSHomeDirectory(),
                            isCancelled: @escaping @Sendable () -> Bool = { false },
                            onProgress: (@Sendable (ScanProgress) -> Void)? = nil) throws -> Result {
        var st = stat()
        guard lstat(path, &st) == 0 else { throw ScanError.cannotOpen(path, errno) }
        let last = (path as NSString).lastPathComponent
        let name = last.isEmpty ? path : last

        guard (st.st_mode & S_IFMT) == S_IFDIR else {
            let node = FileNode(name: name, isDirectory: false,
                                size: Int64(st.st_blocks) * 512,
                                modTime: Int64(st.st_mtimespec.tv_sec))
            var stats = ScanStats()
            stats.fileCount = 1
            stats.totalBytes = node.size
            return Result(root: node, stats: stats, bucketBytes: [.other: node.size], cancelled: false)
        }

        let root = FileNode(name: name, isDirectory: true, size: 0,
                            modTime: Int64(st.st_mtimespec.tv_sec))
        let rootPath = path == "/" ? "" : path
        let engine = Engine(skips: skipPrefixes ?? BulkScanner.defaultRootSkips(for: path),
                            homePath: homePath, isCancelled: isCancelled, onProgress: onProgress)
        let rootBucket = ScanBucket.classify(directoryPath: path, name: name, parent: nil, home: homePath)
        return engine.run(root: root, rootPath: rootPath, rootBucket: rootBucket)
    }

    // MARK: - engine

    private struct Item {
        let node: FileNode
        let path: String
        let bucket: ScanBucket
    }

    /// Thread-safety model: the queue, counters and merge results are guarded
    /// by `cond`. A FileNode's `children` is written exactly once, by the
    /// worker that popped that directory; parents never touch it again until
    /// the final (single-threaded) size fix-up.
    private final class Engine: @unchecked Sendable {
        private let cond = NSCondition()
        private var queue: [Item] = []
        private var pendingCount = 0
        private var cancelled = false
        private var mergedStats = ScanStats()
        private var mergedLinked: [UInt64: Int64] = [:]
        private var duplicateBytes: Int64 = 0
        private var progress = ScanProgress()

        private let skips: [String]
        private let homePath: String
        private let isCancelled: @Sendable () -> Bool
        private let onProgress: (@Sendable (ScanProgress) -> Void)?

        init(skips: [String], homePath: String, isCancelled: @escaping @Sendable () -> Bool,
             onProgress: (@Sendable (ScanProgress) -> Void)?) {
            self.skips = skips
            self.homePath = homePath
            self.isCancelled = isCancelled
            self.onProgress = onProgress
        }

        func run(root: FileNode, rootPath: String, rootBucket: ScanBucket) -> Result {
            queue.append(Item(node: root, path: rootPath, bucket: rootBucket))
            pendingCount = 1
            let workers = max(4, ProcessInfo.processInfo.activeProcessorCount * 2)
            DispatchQueue.concurrentPerform(iterations: workers) { _ in
                self.workerLoop()
            }
            mergedStats.totalBytes -= duplicateBytes
            fixDirectorySizes(root)
            root.size -= duplicateBytes
            // Final progress so the UI's last numbers equal the result's.
            progress.files = mergedStats.fileCount
            progress.bytes = mergedStats.totalBytes
            onProgress?(progress)
            return Result(root: root, stats: mergedStats, bucketBytes: progress.bucketBytes, cancelled: cancelled)
        }

        private func pop() -> Item? {
            cond.lock()
            defer { cond.unlock() }
            while queue.isEmpty && pendingCount > 0 && !cancelled { cond.wait() }
            if cancelled || isCancelled() {
                cancelled = true
                queue.removeAll()
                pendingCount = 0
                cond.broadcast()
                return nil
            }
            guard !queue.isEmpty else { return nil }
            return queue.removeLast()
        }

        private func push(_ items: [Item]) {
            guard !items.isEmpty else { return }
            cond.lock()
            queue.append(contentsOf: items)
            pendingCount += items.count
            cond.broadcast()
            cond.unlock()
        }

        private func finishItem() {
            cond.lock()
            pendingCount = max(0, pendingCount - 1)
            if pendingCount == 0 { cond.broadcast() }
            cond.unlock()
        }

        private func workerLoop() {
            let bufSize = 256 * 1024
            let buf = UnsafeMutableRawPointer.allocate(byteCount: bufSize, alignment: 8)
            defer { buf.deallocate() }

            var local = ScanStats()
            var localLinked: [UInt64: Int64] = [:]
            var localBuckets: [ScanBucket: Int64] = [:]
            var reportedBuckets: [ScanBucket: Int64] = [:]
            var sinceProgress = 0
            var lastReportedFiles = 0
            var lastReportedBytes: Int64 = 0

            while let item = pop() {
                let fd = open(item.path.isEmpty ? "/" : item.path, O_RDONLY | O_DIRECTORY | O_NOFOLLOW)
                guard fd >= 0 else {
                    local.skippedCount += 1
                    finishItem()
                    continue
                }
                local.directoryCount += 1

                var children: [FileNode] = []
                var discovered: [Item] = []
                let rc = BulkScanner.enumerate(dirFD: fd, buffer: buf, bufferSize: bufSize) { entry in
                    if entry.errorCode != 0 || entry.name.isEmpty {
                        local.skippedCount += 1
                        return
                    }
                    if entry.objType == BulkScanner.vDIR {
                        let childPath = item.path + "/" + entry.name
                        if skips.contains(where: { childPath == $0 || childPath.hasPrefix($0 + "/") }) {
                            return
                        }
                        let node = FileNode(name: entry.name, isDirectory: true, size: 0, modTime: entry.modTime)
                        children.append(node)
                        let bucket = ScanBucket.classify(directoryPath: childPath, name: entry.name,
                                                         parent: item.bucket, home: homePath)
                        discovered.append(Item(node: node, path: childPath, bucket: bucket))
                    } else {
                        var alloc = entry.allocSize
                        if entry.objType == BulkScanner.vREG && entry.linkCount > 1 && entry.fileID != 0 {
                            if localLinked[entry.fileID] != nil {
                                alloc = 0
                            } else {
                                localLinked[entry.fileID] = alloc
                            }
                        }
                        local.fileCount += 1
                        local.totalBytes += alloc
                        localBuckets[item.bucket, default: 0] += alloc
                        children.append(FileNode(name: entry.name, isDirectory: false, size: alloc, modTime: entry.modTime))
                        sinceProgress += 1
                    }
                }
                close(fd)
                if rc != 0 { local.skippedCount += 1 }
                item.node.children = children
                push(discovered)
                finishItem()

                if sinceProgress >= 16384, let onProgress {
                    sinceProgress = 0
                    cond.lock()
                    progress.files += local.fileCount - lastReportedFiles
                    progress.bytes += local.totalBytes - lastReportedBytes
                    for (bucket, bytes) in localBuckets {
                        progress.bucketBytes[bucket, default: 0] += bytes - (reportedBuckets[bucket] ?? 0)
                    }
                    let snapshot = progress
                    cond.unlock()
                    lastReportedFiles = local.fileCount
                    lastReportedBytes = local.totalBytes
                    reportedBuckets = localBuckets
                    onProgress(snapshot)
                }
            }

            // Merge this worker's results.
            cond.lock()
            mergedStats.fileCount += local.fileCount
            mergedStats.directoryCount += local.directoryCount
            mergedStats.skippedCount += local.skippedCount
            mergedStats.totalBytes += local.totalBytes
            for (bucket, bytes) in localBuckets {
                progress.bucketBytes[bucket, default: 0] += bytes - (reportedBuckets[bucket] ?? 0)
            }
            for (id, size) in localLinked {
                if mergedLinked[id] != nil {
                    duplicateBytes += size
                } else {
                    mergedLinked[id] = size
                }
            }
            cond.unlock()
        }

        /// Recompute directory sizes bottom-up once the tree is complete —
        /// during the scan, directory nodes never accumulate sizes.
        @discardableResult
        private func fixDirectorySizes(_ node: FileNode) -> Int64 {
            guard node.isDirectory, let children = node.children else { return node.size }
            node.size = children.reduce(0) { $0 + fixDirectorySizes($1) }
            return node.size
        }
    }
}
```

```swift
import Foundation

/// Joins the two passes of a home scan. Pass one measured ~/Library, the
/// dot-folders and every top-level file; pass two measured the remaining
/// top-level directories (its own top-level files are duplicates and dropped).
public enum ScanMerge {
    public static func graft(passTwo: ParallelScan.Result, onto base: ParallelScan.Result) -> ParallelScan.Result {
        let root = base.root
        var stats = base.stats
        var buckets = base.bucketBytes

        var added: [FileNode] = []
        var droppedFiles = 0
        var droppedBytes: Int64 = 0
        for child in passTwo.root.children ?? [] {
            if child.isDirectory {
                added.append(child)
            } else {
                droppedFiles += 1
                droppedBytes += child.size
            }
        }

        root.children = (root.children ?? []) + added
        root.size = (root.children ?? []).reduce(0) { $0 + $1.size }

        stats.fileCount += passTwo.stats.fileCount - droppedFiles
        stats.directoryCount += passTwo.stats.directoryCount - 1 // pass two's own root
        stats.skippedCount += passTwo.stats.skippedCount
        stats.totalBytes += passTwo.stats.totalBytes - droppedBytes
        for (bucket, bytes) in passTwo.bucketBytes {
            buckets[bucket, default: 0] += bytes
        }
        buckets[.other, default: 0] -= droppedBytes // top-level files sat in .other in pass two
        if buckets[.other] == 0 { buckets[.other] = nil }

        // ponytail: a hardlink with one name in each pass is counted twice;
        // accepted — cross-pass hardlinks in a home folder are vanishingly rare.
        return ParallelScan.Result(root: root, stats: stats, bucketBytes: buckets, cancelled: false)
    }
}
```

```swift
    func startScan(path: String) {
        cancelFlag.cancel()
        cancelFlag = CancelFlag()
        scanGeneration += 1
        let generation = scanGeneration
        let flag = cancelFlag

        scanPath = path
        isHomeScan = (path == NSHomeDirectory())
        phase = .scanning
        progress = ScanProgress()
        isPartial = false
        scanStep = isHomeScan ? 1 : 0
        snapshotCount = nil
        let started = Date()

        Task.detached(priority: .utility) { [weak self] in
            let count = SystemDataScan.localSnapshotCount()
            await MainActor.run { self?.snapshotCount = count }
        }

        if isHomeScan {
            runHomeScan(generation: generation, flag: flag, started: started)
        } else {
            runSinglePass(path: path, generation: generation, flag: flag, started: started)
        }
    }

    private func progressSink(generation: Int) -> @Sendable (ScanProgress) -> Void {
        { [weak self] p in
            Task { @MainActor in
                guard let self, self.scanGeneration == generation else { return }
                self.progress = p
            }
        }
    }

    private func runSinglePass(path: String, generation: Int, flag: CancelFlag, started: Date) {
        let sink = progressSink(generation: generation)
        Task.detached(priority: .userInitiated) { [weak self] in
            let result = try? ParallelScan.scan(path: path, isCancelled: { flag.isCancelled }, onProgress: sink)
            let elapsed = Date().timeIntervalSince(started)
            await MainActor.run {
                guard let self, self.scanGeneration == generation else { return }
                self.finishScan(result: result?.cancelled == true ? nil : result, elapsed: elapsed)
            }
        }
    }

    private func runHomeScan(generation: Int, flag: CancelFlag, started: Date) {
        let home = NSHomeDirectory()
        let topLevel = (try? FileManager.default.contentsOfDirectory(atPath: home)) ?? []
        let split = Self.partitionHome(topLevel: topLevel)
        let passOnePaths = split.passOne.map { home + "/" + $0 }
        let passTwoPaths = split.passTwo.map { home + "/" + $0 }
        let sink = progressSink(generation: generation)

        Task.detached(priority: .userInitiated) { [weak self] in
            guard let one = try? ParallelScan.scan(path: home, skipPrefixes: passTwoPaths,
                                                   isCancelled: { flag.isCancelled }, onProgress: sink),
                  !one.cancelled else {
                await MainActor.run { [weak self] in
                    guard let self, self.scanGeneration == generation else { return }
                    self.finishScan(result: nil, elapsed: 0)
                }
                return
            }
            await MainActor.run { [weak self] in
                guard let self, self.scanGeneration == generation else { return }
                self.finishScan(result: one, elapsed: Date().timeIntervalSince(started))
                self.isPartial = true
                self.scanStep = 2
                self.progress = ScanProgress()
            }

            guard let two = try? ParallelScan.scan(path: home, skipPrefixes: passOnePaths,
                                                   isCancelled: { flag.isCancelled }, onProgress: sink),
                  !two.cancelled else { return }
            await MainActor.run { [weak self] in
                guard let self, self.scanGeneration == generation, let root = self.root, let stats = self.stats else { return }
                let base = ParallelScan.Result(root: root, stats: stats, bucketBytes: [:], cancelled: false)
                let merged = ScanMerge.graft(passTwo: two, onto: base)
                self.stats = merged.stats
                self.scanSeconds = Date().timeIntervalSince(started)
                self.isPartial = false
                self.scanStep = 0
                self.rebuildDerived()
                self.refreshVolumeInfo()
                self.treeVersion += 1
            }
        }
    }

    private func finishScan(result: ParallelScan.Result?, elapsed: Double) {
        guard let result else {
            phase = .welcome
            isPartial = false
            scanStep = 0
            return
        }
        root = result.root
        stats = result.stats
        scanDate = Date()
        scanSeconds = elapsed

        // Locate the home subtree: the scan root itself, or /Users/<name>
        // inside a broader scan.
        let homePath = NSHomeDirectory()
        if isHomeScan {
            homeNode = result.root
        } else if homePath.hasPrefix(scanPath) {
            let relative = scanPath == "/" ? String(homePath.dropFirst())
                : String(homePath.dropFirst(scanPath.count + 1))
            var node: FileNode? = result.root
            for component in relative.split(separator: "/") {
                node = node?.child(String(component))
            }
            homeNode = node
        } else {
            homeNode = nil
        }

        if homeNode == nil {
            report = nil
            categoryTotals = []
        }
        section = homeNode != nil ? .systemData : .treemap
        pendingUndoNodes = []
        rebuildDerived()
        treeVersion += 1
        refreshVolumeInfo()
        phase = .done
    }
```
