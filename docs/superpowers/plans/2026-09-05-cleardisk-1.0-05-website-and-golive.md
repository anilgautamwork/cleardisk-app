# ClearDisk 1.0 — Plan 05: Website and Go-Live

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** cleardisk.app sells and delivers the app: landing, buy-now with embedded Stripe Checkout, thank-you with the key and one-click activation, recover, download, three SEO pages, privacy and terms. Then the go-live checklist and the end-to-end verification.

**Architecture:** Plain HTML pages in `web/public/` with one stylesheet, served as static assets by the Worker from plan 01. Two pages carry a little JavaScript: buy-now mounts Stripe embedded Checkout with a client secret from `POST /api/checkout`; thanks polls `GET /api/key`. Light and dark follow `prefers-color-scheme` using the app's palette.

**Tech Stack:** HTML, CSS, vanilla JS, Stripe.js v3, Cloudflare Workers static assets, Cloudflare Web Analytics.

**Spec:** `docs/superpowers/specs/2026-09-05-cleardisk-1.0-production-design.md` (sections 9 and 10)

## Global Constraints

- Price text is "$10" and "one-time" everywhere; never "$9.99", never "subscription" except to say there isn't one.
- No forms of ours collect data; only Stripe Checkout collects the email. The recover page takes an email and posts it to `/api/recover` only.
- Pages: `/`, `/buy-now`, `/thanks`, `/recover`, `/download`, `/clear-system-data-on-mac`, `/mac-storage-full`, `/what-is-system-data-on-mac`, `/privacy`, `/terms`, `404.html`. Filenames are `<slug>.html` in `web/public/` — the assets binding serves `/buy-now` from `buy-now.html` (`html_handling` default `auto-trailing-slash`).
- Every page includes the same header and footer markup verbatim (no templating).
- Google Ads conversion snippet only on `/thanks`. Cloudflare Web Analytics is enabled in the dashboard (automatic injection), no snippet in the pages.
- Screenshots come from the finished app (plans 02–04 done). The DMG comes from `Scripts/release-direct.sh`.
- Commit after every task from the repo root.
