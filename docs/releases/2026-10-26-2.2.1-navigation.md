# ClearDisk 2.2.1 (14): navigation, status and storage review

## Changes

Disk scan, Why Slow and Permissions remain above the scrolling workspace list. Why Slow opens the running-process list; CPU/memory sorting and confirmed quit actions use the existing license and protected-process checks. The horizontal top bar shows disk space, CPU and memory, and enables the optional menu-bar icon. Monitoring runs while the main window is open or the menu bar is enabled; local history respects the existing setting.

The menu shows up to five running apps, larger confirmed Quit buttons, and a Memory/CPU selector without the wrapping visible label (its accessible name remains). After a completed scan, it shows three files of at least 100 MB, cache measurements where available and trashable developer-junk totals. Review links open existing screens; there is no direct deletion in the menu. Scan date, scope and skipped-file limitations remain visible. Incomplete scans cannot advertise old findings.

Permissions is separate from scan phase. Back preserves the previous workspace and completed results, including a scan that finishes while permission help is open. No OS permission is granted automatically.

## Design review

| Before | After | Why |
| --- | --- | --- |
| Performance hidden below storage sections | Fixed Why Slow link | Short, visible route before scanning |
| Tall disk card occupying the sidebar | Horizontal status bar | Keeps navigation within reach |
| Wrapping sort label and small native Quit buttons | Hidden visible label and larger styled buttons | Clearer compact menu and easier targets |
| Menu only showed performance | Completed-scan storage review | Review measured files without automatic deletion |
